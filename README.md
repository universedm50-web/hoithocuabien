## 🚀 HƯỚNG DẪN KHỞI CHẠY TRỰC TIẾP

Dự án được xây dựng bằng kiến trúc web hiện đại chuẩn tĩnh (Static Modern Web), không cần cài đặt dependencies phức tạp.

1. **Cách 1: Mở trực tiếp bằng trình duyệt**
   - Vào thư mục `C:\Users\vu.dominh\Downloads\Hơi thở của biển`
   - Nhấp đúp chuột vào file `index.html` (hoặc chuột phải chọn *Open with Google Chrome / Microsoft Edge*).

2. **Cách 2: Mở qua Live Server hoặc Python HTTP Server (Khuyên dùng)**
   - Mở terminal tại thư mục dự án và chạy:
     ```bash
     python -m http.server 8080
     ```
   - Truy cập vào trình duyệt: `http://localhost:8080`

## 💎 ĐIỂM NỔI BẬT VỀ CÔNG NGHỆ & THIẾT KẾ
- **Bảng màu Luxury:** Deep Ocean Navy (`#031320`), Ocean Blue (`#0284C7`), Champagne Gold Metallic (`#D4AF37`), kết hợp hiệu ứng Glassmorphism mờ đục cao cấp.

- **Trải nghiệm tương tác cao:** Tự động đếm số (IntersectionObserver), tương tác vector 2D bản đồ, lọc sản phẩm realtime, mô phỏng CRM đa kênh, popup reader và AI Chatbot.
